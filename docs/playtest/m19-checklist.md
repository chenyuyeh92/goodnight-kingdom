# 試玩清單:世界 2–5 地形重排

網址:https://chenyuyeh92.github.io/goodnight-kingdom/
(選關畫面按 T 打開測試模式,可以直接選任何一關)

## 每一關都看一下
- [ ] 平台變多,有「上面的路」(彈跳墊、會掉的平台、高台、寶箱),好玩嗎?太難嗎?
- [ ] 上面的路放的位置每關不一樣(前段/中段/後段),有新鮮感嗎?
- [ ] 有沒有哪裡跳不上去、卡住,或一直撞到頭?(請記下第幾關、大概哪裡)

## 各世界
- [ ] 世界 2 沙漠:彈跳墊避開流沙與壓力板;會掉的平台跨過流沙(2-2)。
- [ ] 世界 3 海底:礁石變兩倍(從海底長上來的石柱、從上面垂下來的礁石),要上下穿梭;會不會太擠?礁石的樣子可以嗎(暫時程式畫的,美術組可以重畫)?
- [ ] 世界 4 冰雪:新平台避開冰柱;冰面上的移動平台好跳嗎?
- [ ] 世界 5 火山:每關有一片熔岩改成搭移動平台過去(原本踏腳的岩石拿掉),會不會太難?

## 其他
