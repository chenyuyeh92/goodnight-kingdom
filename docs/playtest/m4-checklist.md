# 第四步「畫你的守衛」試玩清單

## 試玩網址

https://chenyuyeh92.github.io/goodnight-kingdom/

## 怎麼玩

1. 主頁按「畫你的守衛」(鍵盤 3)。背包改成第 4 顆。
2. 守衛房間:
   - 上面切換「幫 A 選」或「幫 B 選」,點一張卡片就選好了。
   - 下面的按鈕:畫新的(輪廓)、畫新的(空白)、下載圖片、刪除(要按兩次)、返回。
3. 畫畫:
   - 左邊:細、中、粗、橡皮擦、油漆桶、復原、清除。
   - 右邊:10 個顏色。
   - 上面:取名字,按儲存。
   - 請畫**面向右邊**的角色;往左走時遊戲會自動翻過來。
4. 存好後自動選給目前的玩家,回主頁開始遊戲就是你畫的守衛。

## 要試的

- 電腦用滑鼠、手機用手指、iPad 用 Apple Pencil 都畫畫看。畫的時候畫面不應該捲動或縮放。
- 輪廓模式用油漆桶幫睡衣上色。
- 什麼都沒畫按儲存,會提示不能存。
- 存滿 8 個後再存,會提示要先刪一個。
- 下載圖片:電腦會下載 PNG;iPhone 可能會開新分頁顯示圖片,長按就能存到相簿。
- 雙人:A、B 各選不同的守衛,進遊戲看是不是各自的圖。

## 要回報的感覺

1. 畫畫工具好不好用?筆的粗細、顏色夠不夠?
2. 畫好的守衛在遊戲裡大小適合嗎?看得清楚嗎?
3. 手機上畫布夠不夠大?
