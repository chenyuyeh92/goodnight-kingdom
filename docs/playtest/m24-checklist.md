網址:https://chenyuyeh92.github.io/goodnight-kingdom/
(第一次按「開始遊戲」會播開場;主選單右上角「故事」可以重看。想重新體驗第一次,可以到設定清除存檔,或用無痕視窗)

## 開場(6 幕,動態繪本)
- [ ] 1 晚安王國的夜景,鏡頭慢慢往右移;2 城下的房子窗戶一盞一盞熄燈;3 屋頂上的影子(美術組的插圖),黑霧飄向牠;4 失眠森林,魔物睜大眼睛、黑色的雪飄下;5 魔物吵鬧、窗戶又亮起;6 兩位守衛的背影往森林走。
- [ ] 字一個一個出現;點一下先把這一幕的字顯示完,再點才到下一幕。手機上點螢幕任何地方都可以。
- [ ] 右上角「跳過」(電腦按 Esc)可以直接跳過整段。
- [ ] 第二次按開始遊戲不會再播。

## 各世界的開頭句
- [ ] 每個世界的第一關(1-1、2-1 … 10-1)第一次進去,黑底白字一句話約 3 秒,點一下或按任意鍵跳過;之後不再出現(重來也不會)。
- [ ] 十句話讀起來有沒有「伏筆」的感覺(魔物夢到的都是人的煩惱)?

## 夢貘的台詞
- [ ] 出場:「不要過來……你們不懂……」
- [ ] 第二階段:「我……快裝不下了……!」;第三階段:「如果我睡著了……這些惡夢,要去哪裡?」(對話框在夢貘頭上)
