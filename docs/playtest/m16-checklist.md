# 試玩清單:手機結算畫面、武器強度、夢貘大惡夢

網址:https://chenyuyeh92.github.io/goodnight-kingdom/

## 手機結算畫面
- [ ] 用手機玩,打關主時一直按著射擊(或搖桿)直到通關,放開後「下一關」「回到選單」「再玩一次」都按得動嗎?
- [ ] 睡著重來、換關之後,搖桿與按鈕還正常嗎?

## 武器強度(稀有度越高越強)
- [ ] 晚安牛奶噴霧:射程變長(約主角 4~5 個身長),一次 4 發、扇形變窄,好用了嗎?會不會太強?
- [ ] 搖籃曲豎琴(SR):射得更快、一顆 2 點,比數羊機槍好用嗎?
- [ ] 棉被迴力鏢(SR):一下 6 點,射得比較快,好用嗎?
- [ ] 月亮催眠燈(SSR):一下 2 點,連射比較久才過熱,是最強的嗎?
- [ ] 枕頭砲:一下 4 點,感覺有沒有比較有力?

## 夢貘大惡夢(10-3)
- [ ] 夢貘換到第二、第三階段時,畫面變紫、出現一道月光,「大惡夢來了!躲進月光裡!」看得懂嗎?
- [ ] 集氣時間(第二階段 3 秒、第三階段 2.8 秒;集氣時夢貘打不動)走得到月光嗎?
- [ ] 沒躲到扣 3 顆愛心,會不會太痛?
- [ ] 兩個人玩時,兩個人擠得進同一道月光嗎?
