## 星星
- [ ] 星星看得清楚嗎?右上角的收集數看得到嗎?

## 綜合考驗
- [ ] 10-1 淺水、荊棘、強風混在一起會不會太難?
- [ ] 10-2 城牆缺口加強風、冰柱,會不會太常掉下去?
- [ ] 10-3 大廳的黑暗,燭台的光夠不夠?

## 小頭目與最終魔王
- [ ] 10-1 失眠月兔:麻糬黏到變慢(不扣愛心)看得出來嗎(「黏住了!」)?
- [ ] 10-2 熬夜孔雀:左右顛倒 2.5 秒會不會太久、太難?小朋友會不會覺得挫折?
- [ ] 10-3 夢貘:吸氣時往反方向跑得掉嗎?三個階段變大看得出來嗎?150 血打得完嗎?
- [ ] 結局的文字可以嗎?要不要再多一點(例如謝謝、角色們一起睡覺的圖)?
