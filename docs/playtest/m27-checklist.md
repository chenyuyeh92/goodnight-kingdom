# 試玩清單:兩支手機線上雙人、主選單音樂、結局第 8 幕

網址:https://chenyuyeh92.github.io/goodnight-kingdom/
需要兩支手機(或一支手機 + 一台平板/電腦)。

## 主選單音樂、結局
- [ ] 主選單、選關、背包、守衛房間、設定都換成美術組的 C 版「冒險前的晚安」。
- [ ] 開頭動畫、結尾動畫也是這首。
- [ ] 結局第 8 幕:人面獅身不再被雪怪擋住(貓頭鷹、火龍、大猩猩、巨鼴鼠也沒有被後排擋住)。

## 開房間、加入房間
- [ ] 手機 A:主選單「雙人遊戲」→ 跳出三個選項:「同一台裝置」「開房間」「加入房間」。
- [ ] 「同一台裝置」跟以前的雙人一樣。
- [ ] 手機 A 選「開房間」→ 畫面出現 6 位數房間號碼,下面寫「等朋友加入…」。
- [ ] 手機 B 選「加入房間」→ 用畫面上的數字鍵輸入號碼 → 按「加入」。
- [ ] 連上後:手機 A 自動進選關畫面;手機 B 整個畫面變成手機 A 的遊戲畫面,也聽得到聲音(沒聲音的話點一下畫面)。

## 一起玩
- [ ] 手機 A 選關卡開始。手機 A 操控玩家 A,手機 B 用自己的按鈕操控玩家 B。
- [ ] 手機 B 的延遲感覺如何?跳躍、射擊會不會慢到不好玩?(同一個 Wi-Fi、不同網路各試一次;例如一支用 Wi-Fi、一支用 4G/5G)
- [ ] 手機 B 的畫面清楚嗎?
- [ ] 打完一關、睡著重來、換下一關,手機 B 都一直看得到、可以操控。

## 房號提示(2026-10-25 加)
- [ ] 開房間後,畫面左下角一直顯示「房號 123 456」(選關、關卡、結算都看得到;手機 B 的畫面也看得到)。
- [ ] 手機 B 按「離開」後再選「加入房間」:上次的房號已經自動填好,直接按「加入」就能回來(3 小時內有效)。

## 斷線與離開
- [ ] 手機 B 按右上角「離開」→ 回到主選單。手機 A 的玩家 B 停住,畫面上方寫「朋友斷線了,等他連回來…」。
- [ ] 手機 B 再「加入房間」輸入同一個號碼 → 又連回來,繼續玩。
- [ ] 手機 A 回到主選單 → 房間關掉,手機 B 顯示「連線中斷了」,過一下顯示「找不到這個房間」。
- [ ] 第三支手機輸入同一個號碼 → 顯示「這個房間已經有兩個人在玩了」。
- [ ] 輸入沒人開的號碼 → 約 12 秒後顯示「找不到這個房間」。
