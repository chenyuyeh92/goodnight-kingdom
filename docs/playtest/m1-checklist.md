# 第一步「手感原型」試玩清單

## 試玩網址

- 一般版:https://chenyuyeh92.github.io/goodnight-kingdom/
- 調整版(右上角有手感調整面板):https://chenyuyeh92.github.io/goodnight-kingdom/?tune=1

請用 Windows 筆電的 Chrome 或 Edge 試玩。這一步還沒有觸控操作,手機和平板先不用測。

## 按鍵

| 動作 | 按鍵 | 也可以用 |
|---|---|---|
| 左右移動 | A、D | ←、→ |
| 往上瞄準 | W | ↑ |
| 蹲下/空中往下瞄準 | S | ↓ |
| 射擊(按住連射) | C | 逗號 , |
| 跳躍 | V | 句號 . |

畫面裡的方塊都是暫時的:黃色是你的角色,米白色方塊是練習用的小羊靶。

## 要測的項目

1. **走路:** 按下會不會馬上走?放開會不會馬上停?
2. **跳躍:** 高度和落下的速度感覺如何?太飄還是太沉?
3. **邊緣起跳:** 從平台邊緣走出去的一瞬間按跳,還跳得起來嗎?
4. **蹲下和通道:** 往右走會遇到一個低矮的天花板。站著過不去,要蹲下(按住 S)才爬得進去。在通道裡放開 S,角色應該維持蹲著,不會卡進天花板。
5. **三方向射擊:** 按住 W 再射擊會往上打;跳起來後按住 S 再射擊會往下打。
6. **連射速度:** 按住 C 的連射速度,覺得太快還是太慢?
7. **打擊感:** 打倒小羊時,畫面會停頓一下、輕微晃動並冒出「Zzz」。份量感夠不夠?
8. **切換視窗:** 按住 D 時按 Alt+Tab 切到別的視窗,再切回來。角色不應該自己一直走。

## 回報方式

有兩種方式,選你方便的:

- **用一句話描述:** 例如「跳太飄」「停下來太突然」「打倒小羊的感覺不夠爽」。
- **自己調數值:** 打開調整版網址,一邊玩一邊拉右上角的滑桿,調到滿意後按「複製數值」,把複製到的內容貼給我。按「重設」可以回到原本的數值。
