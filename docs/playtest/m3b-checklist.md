# 第三步之二「武器、寶箱、背包與道具」試玩清單

## 試玩網址

- 開場選單(可以進背包):https://chenyuyeh92.github.io/goodnight-kingdom/
- 直接進雙人:https://chenyuyeh92.github.io/goodnight-kingdom/?mode=duo

按鍵和之前一樣。武器、寶箱、道具都還是色塊。

## 寶箱

- 靶場有 3 個寶箱(橘色、金邊):
  1. 路上:練習靶之後不遠。
  2. **隱藏寶箱:** 在中段的高平台上,要跳上去。
  3. 第一個戰鬥區之後。
- 走過去碰到就會打開,寶箱上方顯示抽到的武器,例如「SR 搖籃曲豎琴 ★」,下面一行是機率「R 70% / SR 25% / SSR 5%」。
- 抽到的武器立刻換上並補滿彈藥,同時存進背包(重新整理網頁也不會不見)。
- 抽到已經有的武器會升一星,彈藥上限增加;三星再抽到會改掉出牛奶瓶。
- 雙人時給先碰到的人。

## 六把武器

| 等級 | 武器 | 怎麼用 |
|---|---|---|
| R | 數羊機槍 | 按住狂掃,彈藥 120 |
| R | 枕頭砲 | 慢但會穿透,一發 3 傷害,適合排成一排的魔物 |
| R | 晚安牛奶噴霧 | 一次 5 發扇形,射程很短,貼身用 |
| SR | 搖籃曲豎琴 | 音符會自己轉向追魔物,打頭上的蝙蝠很方便 |
| SR | 棉被迴力鏢 | 飛出去再飛回來,穿透;被刺蝟正面擋住會繼續飛,回程打牠背後 |
| SSR | 月亮催眠燈 | 超快連射又穿透,沒有彈藥限制,但會過熱(HUD 熱度條變滿就要等冷卻) |

- 彈藥用完自動換回哈欠泡泡。左上角會顯示武器名稱和剩餘彈藥。
- 枕頭揮擊不受武器影響,過熱時也能揮。
- 睡著重來時,手上的武器和剩下的彈藥會保留。

## 道具(打倒魔物 15% 機率掉出,8 秒後消失)

| 道具 | 顏色 | 效果 |
|---|---|---|
| 熱可可 | 咖啡色 | 射速加倍 10 秒(HUD 出現 ☕) |
