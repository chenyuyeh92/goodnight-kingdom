## 結局(13 幕)
- [ ] 打倒夢貘後播結局:1 夢貘慢慢閉上眼睛;2 泡泡從嘴裡飄出來;3 惡夢泡泡(美術組的插圖);4 守衛自己的惡夢(城門)泡泡飄到守衛面前;5 守衛看著睡著的夢貘;6 夢貘說夢話;7 守衛坐下唱搖籃曲(音符);8 一路哄睡過的魔王一隻一隻走進來;9 泡泡變星星(插圖);10 夢貘微笑(插圖);11 城裡的燈一盞一盞熄滅;12 全黑「晚安。」;13 星空和最後一句話。
- [ ] 第一次看結局不能整段跳過(沒有「跳過」按鈕);之後再看可以跳過。
- [ ] 看完才進「破關!晚安王國」的結算畫面。
- [ ] 看過結局後,主選單右上角「故事」可以選「開場」或「結局」重看。
- [ ] 讀起來的感覺:反轉、溫暖、最後一句有沒有打動你?

## 魔王區的武器寶箱
- [ ] 每一關一進魔王區,馬上有一個武器寶箱。
- [ ] 打魔王時睡著重來,魔王區的寶箱會再出現(每次打魔王都拿得到武器);路上開過的寶箱維持打開。
