# 第三步之三「失眠森林、熬夜貓頭鷹、出發前選武器」試玩清單

## 試玩網址

- 從開場選單開始(建議):https://chenyuyeh92.github.io/goodnight-kingdom/
- 直接進雙人(跳過選武器):https://chenyuyeh92.github.io/goodnight-kingdom/?mode=duo
- 舊的測試靶場:https://chenyuyeh92.github.io/goodnight-kingdom/?level=range

電腦和手機都可以玩。按鍵和之前一樣,美術還是色塊。

## 完整流程

1. 開場選單選「單人」或「雙人」。
2. **選武器:** 背包裡有武器時,會先出現選武器畫面。第一項是「只帶哈欠泡泡」,下面是你拿過的武器(等級、星等、彈藥)。
   - 上下鍵(W/S 或 ↑/↓)移動,C、逗號或 Enter 確認;也可以直接按數字鍵或用手指點。
   - 雙人時玩家 A 先選,再換玩家 B;兩個人可以選同一把,各自滿彈藥。
   - 背包是空的就直接進關卡。
3. 失眠森林三段,再打關主。
4. 打倒貓頭鷹後出現**結算畫面**:通關時間、哄睡幾隻魔物、找到幾個寶箱、這次拿到的武器、睡著重來幾次。按 1 再玩一次,按 2 回到選單。

## 失眠森林地圖

| 段落 | 內容 |
|---|---|
| 第一段(教學) | 鬧鐘蟲、咖啡豆。路上有一個明顯寶箱。中途有一個戰鬥區(兩波)。 |
| 第二段 | 熬夜蝙蝠登場。有一段**低矮通道**要蹲著爬過去。之後一個戰鬥區。**隱藏寶箱**在通道後面三層高平台的最上面,要一層一層跳上去。 |
| 第三段 | 失眠刺蝟登場,混合前面的魔物。一個戰鬥區(兩波)。段落結尾有明顯寶箱。 |
| 關主戰 | 走到森林盡頭,畫面鎖住,熬夜貓頭鷹出現。上方顯示名字和血條。 |

每段開頭都有檢查點(地上的細柱子),全員睡著時從最後經過的檢查點重來。

## 熬夜貓頭鷹怎麼打

- **盤旋:** 在上方左右飄,往下撒一把羽毛(扇形)。往上射牠,羽毛縫隙之間閃躲。
- **俯衝:** 盤旋一陣子後朝玩家衝下來,撞到會扣愛心。看到牠衝下來就往旁邊跑或跳開。
- **三個階段:** 血量剩 2/3 和 1/3 時會停下來發抖,畫面出現「貓頭鷹越來越暴躁了!」,這段時間打不動。之後羽毛更多、更散,俯衝更快。
- **第二階段開始**會叫鬧鐘蟲從畫面兩邊衝進來。
- **第三階段**血條變紅。
- 血量:單人 60,雙人 90。
- 在關主戰睡著重來,從關主前的檢查點開始,貓頭鷹血量回滿。

## 要回報的感覺

1. 每一段的長度和難度:太長、太短、太難、太簡單?
2. 低矮通道和隱藏寶箱找不找得到、跳不跳得上去?
3. 貓頭鷹的血量和節奏:打多久?太硬還是太快倒?羽毛躲不躲得開?
4. 哪裡卡關、睡著最多次?
5. 從頭到通關大概花多久(結算畫面上有時間)?
6. 選武器畫面清不清楚?手機上點選順不順?
