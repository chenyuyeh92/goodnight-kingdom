# 第六步之一「音效、配樂與設定」試玩清單

## 試玩網址

https://chenyuyeh92.github.io/goodnight-kingdom/

**請開聲音。** 手機要先點一下畫面才會出聲;iPhone 側邊的靜音開關打開時不會有聲音。

## 聽聽看

| 地方 | 配樂 |
|---|---|
| 主頁、選關、背包、守衛房間、設定 | 布拉姆斯《搖籃曲》(音樂盒) |
| 1-1 草原(白天) | 《賈克修士》(兩隻老虎) |
| 1-2 河邊(黃昏) | 《搖籃曲》慢版 |
| 1-3 森林(晚上) | 《小星星》 |
| 關主、小頭目 | 《賈克修士》小調快版 |

音效:射擊「啵」、打中、魔物睡著的「叮咚」、受傷、跳躍、開寶箱的琶音、撿道具、掉進河裡、關主出現、通關的小樂句……都是程式合成的,沒有用到任何音檔。

## 設定(主頁第 5 顆,鍵盤 5)

- 音樂、音效音量各 0–10(鍵盤:上下選、左右調;手機點 − / +)。
- 全部靜音。
- 清除所有存檔(背包、通關紀錄、畫的守衛;要按兩次)。
- 重新整理後設定還在。

## 換成你自己錄的音樂

把錄音檔放進 `public/assets/music/`,在同一個資料夾的 `tracks.json` 寫上哪一首用哪個檔案(說明在 README)。檔案給我也可以,我幫你放。

## 要回報的感覺

1. 音效會不會太吵、太小聲,或哪一個聽起來怪?

3. 配樂的曲子和速度適合各個時段嗎?想換成哪些曲子?
4. 手機上有沒有聲音出不來的情況?
