## 測試模式(先試這個)
- [ ] 選關畫面左下角「測試模式」按一下(或鍵盤 T)→ 所有世界、所有關卡都能點
- [ ] 卡片上的「直接打關主」(或 Shift+數字)→ 一出發走幾步就是關主
- [ ] 再按一次關掉,恢復照順序解鎖
- (上市前會把這個按鈕整個拿掉)

## 游泳手感(3-1 珊瑚礁淺海)
- [ ] 按一下跳躍往上划、按住往上游、放開慢慢沉:會不會太飄或太重?
- [ ] 按住下往下潛、子彈往下射,好不好用?
- [ ] 頂到水面會停住,有沒有卡卡的感覺?
- [ ] 手機上:按住跳躍鈕往上游順不順?
- [ ] 小頭目**失眠寄居蟹**:縮殼滑過來時游上去躲,好不好躲?(圖是程式先畫的)

## 3-2 沉船拱門
- [ ] 水流推的力道:逆流會不會太累?順流會不會太快?
- [ ] 小丑魚成群、章魚噴墨汁、河豚膨脹擋子彈,好不好認?
- [ ] 小頭目**熬夜電鰻**:細線預告看得清楚嗎?來得及游開嗎?(圖是程式先畫的)

## 3-3 深海遺跡 → 亞特蘭提斯神殿
- [ ] 氣泡柱好不好用?高處的寶箱拿得到嗎?
- [ ] 關主**尼斯湖水怪**:衝撞躲得掉嗎?泡泡扇、小丑魚會不會太多?
- [ ] 三小關各花了幾分鐘?(目標 4–5 分鐘)
