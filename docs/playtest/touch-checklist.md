# 手機觸控試玩清單

## 怎麼開始

1. 用 iPhone 的 Safari 打開:https://chenyuyeh92.github.io/goodnight-kingdom/
2. **把手機轉成橫向**(直拿會顯示提示)。
3. 點「單人」開始。
4. 小技巧:在 Safari 按「分享 → 加入主畫面」,從主畫面打開,畫面會更大、不會被網址列擋住。

## 操作

| 動作 | 怎麼做 |
|---|---|
| 移動 | 左半邊任何地方按住,往左右拖 |
| 往上瞄準 | 往上拖(可以同時往右拖,邊走邊往上瞄準) |
| 蹲下 / 空中往下瞄準 | 往下拖 |
| 射擊 | 按住右下的「射擊」,會連射;貼近魔物會自動揮枕頭 |
| 跳躍 | 右下角的「跳」 |

左手搖桿、右手射擊和跳躍可以同時按。

## 要回報的感覺

1. 搖桿靈不靈敏?要拖多遠才會走?會不會太容易誤觸往上或往下?
2. 射擊和跳躍按鈕的大小、位置順不順手?有沒有擋到畫面?
3. 會不會不小心按錯、畫面被捲動或放大?
4. 要不要讓按鈕可以自己拖到喜歡的位置?

用一句話描述,或截圖給我都可以。
