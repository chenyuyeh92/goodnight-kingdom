## 打擊感
- [ ] 開槍時槍口有閃一下嗎?
- [ ] 打中魔物有噴火花、小魔物會往後退一點並壓扁一下嗎?
- [ ] 枕頭砲、迴力鏢開火時角色往後頓一下、畫面輕震,感覺有力嗎?會不會太晃?
- [ ] 打倒魔物噴出一圈星星,好看嗎?

## 爽快感
- [ ] 2 秒內接連打倒魔物,右上角出現「連續哄睡 ×N!」,數字越大越大越亮;小朋友會想挑戰更高嗎?
- [ ] 開寶箱時畫面中間跳出武器名稱(R 藍、SR 紫、SSR 金+光圈),撿到道具也跳出名稱;夠顯眼嗎?
- [ ] 結算畫面多一行「最多連續哄睡 N 隻」。
