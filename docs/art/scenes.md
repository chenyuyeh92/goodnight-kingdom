# 場景背景（給程式那邊接）

2026-10-21 第一版。規則見 `docs/art/worlds.md`「背景規則」：每個世界 4 個場景（白天→黃昏→晚上→深夜），場景之間有過渡圖。
檔案都在 `public/assets/backgrounds/`，高度都是 540。

**怎麼用：**
- 每個場景三層：遠景（不透明，捲動最慢）、中景（透明）、近景（透明，捲動最快）。各自重複排列就能一直捲動，左右無縫。
- 場景換到下一個時，先放一張「過渡圖」（寬 1440）：它的左邊緣接前一個場景，右邊緣接下一個場景，中間 480 px 慢慢換過去。三層各有自己的過渡圖，跟著各自的捲動速度走。
- 建議切換點放在檢查點附近，程式可以再加淡入淡出。
- 近景都在地面線（y=480）附近或以下，不擋魔物的腳。

## 已知問題

- 世界 1 草原的中景（圓樹、柵欄）和河邊的中景（蘆葦）、世界 2 黃昏和深夜的近景（沙丘）是程式畫的，比較簡單。
- 世界 2 神殿中景裡的雕像是剪影，看起來有點像人影。
- 過渡圖中間那段是兩個場景疊在一起淡入淡出，中景的剪影會有一點重影。
