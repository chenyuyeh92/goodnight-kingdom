# 第六步之一「音效、配樂與設定」實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 遊戲有聲音:射擊、命中、魔物睡著、受傷、跳躍、開寶箱、撿道具、掉進河裡、關主、通關、選單都有音效;主頁、每個小關、關主戰有配樂;主頁新增「設定」畫面調音樂與音效音量、靜音,以及清除存檔。

**決定(葉宸佑 2026-10-22 授權連續做三個部分,以下是我依企劃做的決定):**
- 目前沒有任何聲音素材。音效全部用程式即時合成(WebAudio),不需要下載檔案,也沒有授權問題。
- 配樂先用程式合成的「音樂盒」版本,曲子用已過著作權的搖籃曲與童謠(布拉姆斯《搖籃曲》、《小星星》等),依時段換曲:白天輕快、黃昏柔和、晚上安靜、關主戰加快。
- 葉宸佑之後錄的正式配樂可以直接放進 `public/assets/music/`,並在 `tracks.json` 登記,遊戲就會改播錄音檔,不用改程式。
- 主頁第 5 顆按鈕「設定」(美術已有按鈕圖)。

## Global Constraints

- 手機瀏覽器要使用者先點一下才能出聲:第一次點擊或按鍵時才啟動聲音。
- 音量設定存在 `gk.settings.v1`;壞資料用預設值(音樂 6、音效 8,滿分 10)。
- 連射武器(數羊機槍 70ms、月亮燈 60ms)的射擊聲要限制頻率,不能吵。
- 沒有聲音裝置或瀏覽器不支援時,遊戲照常可以玩。

## Review Focus

1. 手機(iOS Safari)第一次互動後才出聲,不會報錯或卡住。
2. 換場景、重來時配樂不會疊在一起或越來越大聲。
3. 音量 0 或靜音時真的沒有聲音;設定重新整理後還在。
4. 大量同時發生的事件(一次打倒很多魔物)不會爆音或讓效能變差。
5. 曲子是公有領域(作曲者過世超過 70 年)。

## Tasks

1. **純資料與邏輯(Vitest):** `src/audio/recipes.ts` 音效配方(音高、波形、長度、包絡)、`src/audio/tunes.ts` 曲子(音名、拍子),`src/audio/settings.ts` 音量設定存檔、`src/audio/throttle.ts` 頻率限制。
2. **播放:** `src/audio/audio.ts` 管理 AudioContext、音效與配樂的音量、配樂排程與淡入淡出、錄音檔優先;第一次互動才啟動。
3. **接進遊戲:** 各場景觸發音效;主頁、選關、每關、關主戰、通關播對應配樂;`GkDebug` 記錄播過的音效供測試。
4. **設定畫面 `SettingsScene`:** 音樂音量、音效音量(左右鍵或 − / + 按鈕)、全部靜音、清除存檔(按兩次);主頁第 5 顆按鈕。
5. **e2e:** 射擊/打倒/受傷會觸發音效;設定調整後重新整理還在;靜音時不播;換關後只有一首配樂。
6. **文件:** 企劃補聲音一節、`public/assets/music/README.md` 說明怎麼放錄音檔、試玩清單 `docs/playtest/m6a-checklist.md`。
