# 手感強化 + 武器拿在手上 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 射擊、打中、打倒都有清楚的聲音與畫面回饋,守衛手上拿著目前的武器。

**Architecture:** 純邏輯(連擊計數、退後速度、射擊聲間隔、武器握法)放新檔 `src/game/feel.ts` 做單元測試;聲音在 `src/audio/` 加每把武器的射擊聲與同時發聲上限;畫面效果在 `TestRangeScene`(火花、閃光、連擊、撿到武器的大字)、`PlayerEntity`(手上的武器)、`EnemyEntity`(退後、壓扁)。

**Tech Stack:** Phaser 4.2.1、TypeScript、Vite、vitest、Playwright。

**Spec:** `docs/superpowers/specs/2026-10-23-feel-weapons-story-design.md` 第一部分。

## Global Constraints

- 不改子彈的發射位置與速度(`muzzleOffset`、`bulletVelocity` 不動):手上的武器圖是「把槍口對到現在的發射點」,遊戲判定完全不變。
- 不需要新美術圖;火花、星星用程式產生的小圓點貼圖 `gk-spark`(白色 8×8,用 tint 上色)。
- 新的畫面文字(「連續哄睡 ×N!」、「最多連續哄睡 N 隻」)要重新產生字型(`python3 tools/build_web_assets.py`,字型單元測試會檢查缺字)。
- 每把武器的射擊聲最短間隔 = 射擊間隔 × 0.8;同時最多 12 個音效聲音。
- 退後速度 = min(120, 30 × 傷害) px/s,持續 120 ms;壓扁 80 ms(寬 ×1.15、高 ×0.85);魔王與正面擋下的不退。
- 後座力武器:pillowCannon、blanketBoomerang(第二部分再加新武器);角色水平速度 −facing×60 一格,畫面震 80 ms、強度 0.002。
- 連擊:上一隻打倒後 2000 ms 內再打倒就 +1;×3 起黃 `#ffe08a`、×5 橘 `#ffb060`、×10 粉紅 `#ff8ac8`;字大小 22 + 2×min(N,10) px;只有 N ≥ 2 才顯示。
- 撿到武器的大字:R `#8ac8ff`、SR `#d0a0ff`、SSR `#ffd060`(SSR 多一圈金色光圈),0.9 秒後淡出。

## Review Focus

- 雙人模式:兩位玩家各自拿著自己的武器、各自的槍口閃光;連擊兩人共用一個計數。→ Task 3、5 的 e2e 用 `mode=duo` 檢查兩人的 held。
- 睡著(down)、蹲下、往上射、空中往下射時,手上武器的位置與角度不會飛出去或卡在身體裡;睡著時藏起來。→ Task 1 的單元測試涵蓋四種姿勢;Task 3 的 e2e 檢查睡著時 `held` 為 null。
- 月亮燈(60 ms 連射)與熱可可(射速加倍)時聲音不會爆:同時聲音上限生效。→ Task 2 單元測試 `voiceCap`。
- 練習靶(Target,不是魔物)被打中也要有火花但不退後;盾牌擋下噴灰色火花不退後。→ Task 4 e2e:打刺蝟正面只有灰火花、不退。
- 換關、重來時連擊歸零,但「最多連續哄睡」跨重來保留(跟其他統計一樣存在 stats)。→ Task 5 單元測試與 e2e。

### Task 1: 手感的純邏輯 `src/game/feel.ts`

**Files:**
- Create: `src/game/feel.ts`
- Test: `tests/feel.test.ts`

**Interfaces:**
- Produces:
  - `shootGapMs(intervalMs: number): number` — `intervalMs * 0.8`
  - `knockbackSpeed(damage: number): number` — `Math.min(120, 30 * damage)`
  - `KNOCK_MS = 120`, `SQUASH_MS = 80`, `SQUASH = { x: 1.15, y: 0.85 }`
  - `RECOIL_WEAPONS: ReadonlySet<WeaponId>`(pillowCannon、blanketBoomerang)、`RECOIL_VX = 60`
  - `interface Combo { count: number; sinceMs: number; best: number }`、`NO_COMBO`、`COMBO_WINDOW_MS = 2000`
  - `comboDefeat(c: Combo): Combo`(sinceMs ≤ 2000 且 count>0 → count+1,否則 count=1;sinceMs 歸 0;best 取最大)
  - `comboTick(c: Combo, dtMs: number): Combo`(sinceMs 加上 dt;超過 2000 時 count 歸 0,best 保留)
  - `comboStyle(n: number): { color: string; fontSize: number }`
  - `MUZZLE: Readonly<Record<WeaponId, { x: number; y: number }>>` — 武器圖上槍口的位置(0–1 比例),例如 sheepGun `{ x: 1, y: 0.45 }`、moonLamp `{ x: 0.5, y: 0 }`(燈頭朝上的圖)。月亮燈圖是直的:另外有 `ART_ANGLE: Partial<Record<WeaponId, number>>`(moonLamp 90:圖轉 90 度才是槍口朝右)。
  - `heldPose(aim: Aim, facing: Facing): { angle: number; flipX: boolean }` — forward:角度 0、朝左翻轉;up:朝右 −90、朝左 −90 且翻轉;down:90(朝左時翻轉)。角度要再加上 `ART_ANGLE`。
  - `HELD_SCALE = 0.8`

  - `shootGapMs`:每把武器(`WEAPONS` 全部,哈欠泡泡用 `DEFAULT_TUNING.fireIntervalMs`)的間隔都 `< 射擊間隔` 且 `> 0`。
  - `knockbackSpeed(1) === 30`、`knockbackSpeed(6) === 120`、`knockbackSpeed(100) === 120`。
  - 連擊:`comboDefeat(NO_COMBO).count === 1`;1999 ms 後再打倒 → 2;2001 ms 後 `comboTick` → count 0、best 保留 2;再打倒 → 1。
  - `comboStyle(2).color` 是白 `#f3e9d2`、`comboStyle(3).color === '#ffe08a'`、`(5) '#ffb060'`、`(10) '#ff8ac8'`;`comboStyle(20).fontSize === comboStyle(10).fontSize === 42`。
  - `MUZZLE` 有每一個 `WeaponId`,且 x、y 都在 0–1。
  - `heldPose('forward', -1).flipX === true`、`heldPose('up', 1).angle === -90`、`heldPose('down', 1).angle === 90`。
- [ ] **Step 2:** `npx vitest run tests/feel.test.ts` → FAIL(找不到模組)。

### Task 2: 每把武器自己的射擊聲、打中/打倒聲、同時聲音上限

- 豎琴每發 pitch 從 `[1, 1.125, 1.25, 1.5]` 隨機挑。
