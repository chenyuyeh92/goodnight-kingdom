# 第三步之五「美術第二批、封面主頁、世界 1 三小關(草原、河邊、深林)」實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 接上美術第二批素材(關著的寶箱、正面刺盾刺蝟與滾球、6 種子彈圖、粉圓字型、封面與主頁按鈕、世界 1 四個場景背景與過渡圖);做出世界 1 的選關畫面,以及 1-1 草原(白天)、1-2 河邊(黃昏,含水的玩法);現有失眠森林變成 1-3 深林(晚上)→ 貓頭鷹大樹(深夜)。

**Architecture:** `LevelDef` 新增「場景」資料(哪一段用哪組三層背景、在哪裡換場),背景模組依資料在每一層各自接上過渡圖。水的規則(淺水變慢、河溝掉下去)寫成純函式。選關與存檔記錄「已通關的小關」。字型子集化成 woff2(只留遊戲用到的字),背景轉 WebP 縮小下載量,都用程式在建置時處理,不改美術原檔。

**Spec:** 企劃 6.3、6.4(十大世界)、美術 `docs/art/scenes.md`、`docs/art/ui.md`、`docs/art/worlds.md`、`docs/art/level1-assets.md`(合併後)。

## 已確認的決定(葉宸佑 2026-10-22)

- 一個小關一個場景:1-1 草原(白天)、1-2 河邊(黃昏)、1-3 深林(晚上)打到尾端進貓頭鷹大樹(深夜)。一個世界玩完剛好「過了一天」。
- 河邊加一點水的玩法:淺水走起來變慢、要跳過的河溝、漂浮荷葉踏板;掉進河溝扣一顆愛心,從岸邊重新出來。

## Global Constraints

- 沿用前面計畫的 Global Constraints(判定與外觀分開、圖片載入失敗退回色塊、素材路徑用 `BASE_URL`)。
- 每小關一局目標 4–5 分鐘,以邊走邊打為主;1-1、1-2 結尾各有一個小頭目(美術還沒有小頭目圖,先用現有魔物放大 1.5 倍、加顏色區分,之後請美術補)。
- 美術原檔不修改;WebP、字型子集是建置時產生的檔案。
- 字型依 OFL:子集化後改名(例如「GK Huninn」),遊戲網站附上授權檔。

## Review Focus

1. **換場與過渡圖:** 三層各自在正確位置接上過渡圖,不會出現接縫、空白或跳動;重來時從檢查點開始背景也正確。
2. **水的規則:** 掉進河溝不會卡死、不會無限扣血、雙人時一人掉下去另一人不受影響;魔物不會掉進河溝讓戰鬥區清不完。
3. **選關與存檔:** 只能玩已解鎖的小關;存檔壞掉或舊版存檔都能正常開始(只開放 1-1);通關才解鎖下一關。
4. **字型:** 子集裡要包含遊戲所有會顯示的字,漏字會變成方框 → 單元測試掃描原始碼裡的中文字。
5. **下載量:** 第一次進遊戲只載入主頁和選到的那一關需要的圖,不要一次載 18 MB。

### Task 6: 1-1 草原(白天)

- 草原入口,白天背景 `w1-s1`。約 10000 寬、五段、零星魔物約 35 組;魔物以鬧鐘蟲、咖啡豆為主,後段加蝙蝠;戰鬥區 2 個;寶箱 3 個(一個藏在高處)。
- 結尾小頭目「大鬧鐘蟲」:鬧鐘蟲放大 1.5 倍、血量 25、會叫小鬧鐘蟲;打倒後通關。
- 教學提示放在前面(跳、蹲、往上射、近身揮枕頭)。

### Task 7: 1-2 河邊(黃昏)與水的玩法

- 河邊背景 `w1-s2`。約 10000 寬、五段。
- 水的玩法(純函式 + 關卡資料):
  - 淺水區:走路速度 ×0.6、跳躍略低,有水花。
  - 河溝:地面中斷一段,要跳過去;掉下去扣一顆愛心,0.5 秒後從最近的岸邊重新出來(短暫無敵)。
  - 荷葉踏板:浮在河溝上,輕輕上下漂,可以站。
  - 魔物不會走進河溝(走到邊緣會轉身);會飛的照飛。
- 結尾小頭目「刺蝟隊長」:刺蝟放大 1.5 倍、血量 30,滾動更頻繁。
- 測試:水的純函式(速度、掉落、重生點)、e2e 掉進河溝扣一顆並回到岸邊、雙人一人掉下去。
