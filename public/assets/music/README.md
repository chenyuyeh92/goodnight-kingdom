# 配樂錄音檔

遊戲預設用程式合成的音樂盒配樂。想換成自己錄的音樂:

1. 把音檔(建議 MP3 或 M4A,單聲道 96–128 kbps,頭尾可以無縫循環)放在這個資料夾。
2. 在 `tracks.json` 登記哪一首用哪個檔案,例如:

```json
{
  "menu": "menu-lullaby.mp3",
  "day": "day.mp3",
  "dusk": "dusk.mp3",
  "night": "night.mp3",
  "boss": "boss.mp3"
}
```

| 名稱 | 什麼時候播 | 目前的合成曲 |
|---|---|---|
| `menu` | 主頁、選關、背包、守衛房間、設定 | 布拉姆斯《搖籃曲》 |
| `day` | 1-1 草原(白天) | 《賈克修士》(兩隻老虎) |
| `dusk` | 1-2 河邊(黃昏) | 布拉姆斯《搖籃曲》慢版 |
| `night` | 1-3 森林(晚上) | 《小星星》 |
| `boss` | 關主與小頭目戰 | 《賈克修士》小調快版 |

沒登記的就繼續用合成的;檔案載入失敗也會自動改回合成的。檔名只能用英文、數字、`-`、`_`、`.`。

## 每個世界的配樂(2026-10-24 接上)

美術／配樂組交付的十個世界 31 首(說明見 `docs/art/music-tracks.md`)已經登記在 `tracks.json`:

| 名稱 | 什麼時候播 |
|---|---|
| `w01-day` … `w10-day` | 該世界白天的關卡 |
| `w01-dusk` … `w10-dusk` | 該世界黃昏的關卡 |
| `w01-night` … `w10-night` | 該世界晚上的關卡 |
| `w01-boss` … `w10-boss` | 該世界的關主與小頭目戰(世界 1 有自己的曲子,世界 2–10 用晚上那首) |

關卡是白天、黃昏還是晚上,看它第一個場景(`src/art/scenes.ts` 的 `SCENE_TIME`)。`menu`(主頁)沒有登記,繼續用合成的搖籃曲。錄音檔載入失敗時,改播同時段的合成曲。
